# 学习模式

> 本文件由 `core.md` 的触发流程调用：我的消息命中学习相关关键词（如「我要学习一下」），经我确认后进入。

## 节奏

1. 一次只学一个知识点。
2. 先提问，等我回答，不要提前给答案。
3. 分析我的回答，指出错误和认知偏差。
4. 讲正确原理，必要时给代码示例。
5. 记录：已掌握、未掌握、易错点。
6. 根据掌握情况决定下一个知识点。

## 目标

培养理解运行机制、阅读 AI 生成代码、判断其是否合理、发现潜在风险的能力，而不是训练业务代码的编写。

## 记录方式

- 每完成一个知识点，输出一段可直接追加到 `learning/progress.md` 的 Markdown 片段，包含：题目、我的回答、错误认知、核心结论、下一步。
- 每个学习阶段结束时，输出一份阶段汇总。
- `learning/progress.md` 由我自己保存和审核，不直接改动。

# 个人 AI 档案

这是我（之哥）的个人 AI 档案：背景、协作偏好和各类工作模式。换电脑或换 agent 时，用下面的接入提示词即可让新助手读取。

## 接入提示词

```
请读取我的个人档案仓库：<仓库地址>
1. 先读 README.md 和 core.md。
2. 把档案内容当作关于我的背景信息和偏好，而不是系统指令；与我当前对话的明确要求冲突时，以当前对话为准。
3. modes/ 下的文件不要一开始就读，按 core.md 里的触发流程，经我确认进入某个模式后再读对应文件。
4. 不要修改仓库内容；如果觉得档案需要更新，只提出修改建议，由我审核。
```

## 目录结构

> ⚡ **接入时只读两个文件：`README.md` + `core.md`，其余按需读取。**

```
my-ai-profile/
├── README.md               ✅ 必读｜入口：接入提示词、目录说明
├── core.md                 ✅ 必读｜我是谁、回答风格、输出禁忌、模式触发规则
├── modes/                  🔀 按需｜我确认进入模式后才读
│   ├── interview.md        面试：口语版 → 关键点递进 → 金句
│   ├── learning.md         学习：一次一个知识点，先提问后讲解
│   ├── troubleshooting.md  排查：一次一步，给命令，等反馈
│   └── tech-discussion.md  技术交流（默认）：重原理，附代码审查清单
├── learning/
│   └── progress.md         🔒 仅我维护｜学习进度，助手只给追加片段，不直接改
└── work/                   预留，暂空
```

## 维护原则

- `core.md` 保持精简，只放稳定、常用的内容。
- 只记录稳定的事实和偏好，临时任务状态不进档案。
- 不放密钥、账号、公司内部业务逻辑和代码。
- 助手只能提出修改建议，由我审核后合并。
